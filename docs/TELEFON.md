# Проверка на телефоне — по шагам

Нужно: ноутбук с Windows и этим репозиторием, телефон (iPhone или Android), одна Wi‑Fi сеть
между ними — проще всего точка доступа.

## 1. Сеть

Любой из вариантов:

* **Телефон раздаёт интернет, ноутбук подключён к нему.** iPhone: Настройки → Режим модема.
  Android: Настройки → Точка доступа. Ноутбук подключается к этой сети как к обычному Wi‑Fi.
* **Ноутбук раздаёт, телефон подключён.** Windows: Параметры → Сеть и Интернет →
  Мобильный хот-спот → Вкл. Адрес ноутбука в этой сети обычно `192.168.137.1`.

VPN на ноутбуке (WireGuard и т. п.) можно не выключать — сервер покажет его адрес последним
с пометкой, что телефон его не видит.

## 2. Запуск на ноутбуке

Дважды щёлкните **`start.cmd`** в папке проекта (или в терминале: `.\start.cmd`).

Скрипт сам проверит Node.js, поставит зависимости, создаст сертификаты и покажет:

```
[Беспроводная сеть] точка доступа Windows (телефон подключён к ноутбуку)
  1) Первый раз — установка сертификата:  http://192.168.137.1:8080/
  2) Приложение:                          https://192.168.137.1:8443/
  QR для первого шага …
```

Если сеть подключили после запуска — новый адрес появится в окне сам, перезапускать не надо.

Если Windows спросит «Разрешить node.exe доступ к сетям» — разрешите (отметьте обе галочки).
Если не спросила, а телефон страницу не открывает — один раз запустите **`firewall.cmd`**
(попросит права администратора, откроет порты 8080–8099 и 8443–8462 только для локальной подсети).

## 3. Сертификат на телефон (один раз)

Камера в браузере работает только по HTTPS. У ноутбука нет «настоящего» сертификата,
поэтому ставим свой. **Это безопасно:** он ограничен частными адресами (192.168.*, 10.*,
172.16–31.*, 100.64–127.*) и именем localhost — подделать им банк или почту невозможно,
телефон такой сертификат отвергнет (это проверяет тест `tests/unit/x509.test.js`).
Ключ лежит только на ноутбуке в `.certs/` и в git не попадает.

Наведите камеру телефона на QR из окна (или наберите адрес из пункта 1) — откроется
страница с инструкцией именно для вашего телефона:

**iPhone (Safari):**
1. «Скачать сертификат» → «Разрешить».
2. Настройки → вверху «Профиль загружен» → Установить.
3. Настройки → Основные → Об этом устройстве → **Доверие сертификатам** → включить «BurstCam Local CA».

**Android (Chrome):**
1. «Скачать сертификат».
2. Настройки → Безопасность → Дополнительно → Шифрование и учётные данные → Установка
   сертификата → **Сертификат ЦС** → «Всё равно установить» → выбрать `BurstCam-CA.crt`.
   (Путь у производителей разный — ищите в настройках «сертификат ЦС».)

## 4. Приложение

Откройте адрес из пункта 2 (`https://…:8443/`), разрешите камеру.

* **Касание** кнопки — одно фото. **Удержание** — серия, счётчик над кнопкой.
* Миниатюра слева → галерея. Серия — одна плитка со значком и числом кадров.
* В просмотре: свайп — листать, щипок / двойное касание — увеличить, смахнуть вниз — закрыть,
  касание — спрятать кнопки. Корзина — удалить, стрелка — «Сохранить / поделиться».
* В галерее «Выбрать» (или долгое касание плитки) — выбрать несколько и удалить разом.
* Пока прошлое фото сохраняется, вокруг кнопки крутится жёлтое кольцо — новое фото будет после него.
* **Шестерёнка** справа вверху — настройки: объектив, родное фото или кадр потока,
  «Определить режимы камеры» (реальные разрешения и частоты), качество JPEG.
  Кнопка слева вверху и «0,5×» над спуском переключают объективы.
* Чтобы узнать всё про камеры конкретного телефона: удерживайте строку «Фото … Мп» вверху →
  `diag.html` → «Опросить камеры».
* Установить как приложение: iPhone — «Поделиться» → «На экран „Домой“»;
  Android — меню ⋮ → «Установить приложение».

## 5. Если что-то не так

| Симптом | Что сделать |
|---|---|
| Телефон не открывает страницу | тот же Wi‑Fi? адрес из окна сервера? запустить `firewall.cmd` |
| «Подключение не защищено» | сертификат не установлен или (iPhone) не включено «Доверие сертификатам» |
| «Нет доступа к камере» | iPhone: Настройки → Safari → Камера → Разрешить. Android: значок слева от адреса → Разрешения |
| Серия медленная | удерживайте строку «Мп · к/с» вверху → откроется `diag.html` → «Запустить замер» → пришлите текст из блока внизу |
| Сменился ноутбук / потеряли `.certs` | `scripts\new-ca.ps1`, затем поставить сертификат заново |

Остановить сервер — `Ctrl+C` в его окне.

Если порт 8080 или 8443 занят другой программой (на Windows 8080 часто держит системная
служба), сервер сам возьмёт следующий свободный и покажет его в окне — используйте адреса
именно оттуда.
