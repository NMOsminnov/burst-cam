# BurstCam

PWA-камера для iPhone и Android: **касание — фото без подтверждений** (на Android — родной
снимок полного разрешения сенсора), удержание — серия из видеопотока. Выбор объектива
(ультраширик), режима камеры и качества JPEG. Галерея с сериями, просмотр со свайпом и
увеличением, удаление, «Сохранить / поделиться».
Работает без сети после первого открытия.

## Быстрый старт

1. Подключите телефон и ноутбук к одной сети (точка доступа).
2. Запустите **`start.cmd`** — в окне появятся адреса и QR-код.
3. На телефоне откройте первый адрес (`http://…:8080/`), поставьте сертификат по инструкции на странице.
4. Откройте второй адрес (`https://…:8443/`) — камера.

Подробно, с решением проблем: [docs/TELEFON.md](docs/TELEFON.md).

## Скрипты

| Что | Как |
|---|---|
| Запустить сервер | `start.cmd` (или `scripts\start.ps1 -Port 8443 -HttpPort 8080`) |
| Открыть порты в брандмауэре (один раз, админ; обычно не нужно, если Windows уже разрешила node.exe) | `firewall.cmd`; убрать — `scripts\firewall.ps1 -Remove` |
| Все проверки | `test.cmd`; только юнит — `scripts\test.ps1 -Unit` |
| Новый сертификат CA | `scripts\new-ca.ps1` |
| Перерисовать иконки | `npm run icons` |

Нужен только [Node.js](https://nodejs.org) 18+ (`winget install OpenJS.NodeJS.LTS`). Сборки нет —
приложение из чистых ES-модулей.

## Как устроено

Почему серия идёт из видеопотока, как выжимается максимальное разрешение, почему JPEG
сжимается нативно в воркерах, а не WASM-кодером, и чем отличаются модули iOS и Android —
в [docs/ANALIZ.md](docs/ANALIZ.md).

```
app/                     приложение (раздаётся как есть)
  js/core/               ядро: планировщик серии, жест, сжатие, хранилище, камера
  js/platform/           android.js и ios.js — платформенные модули; stream.js — подбор разрешения
  js/workers/            capture.js — кадры камеры; encoder.js — JPEG + IndexedDB
  js/ui/                 экран камеры, галерея/серия, просмотр
  diag.html              замеры на конкретном телефоне
server/                  HTTPS-сервер и свой мини-УЦ с ограничением имён (без openssl)
scripts/, *.cmd          запуск, брандмауэр, тесты
tests/unit, tests/e2e    юнит-тесты (node --test) и сквозные (Playwright, поддельная камера)
```

Тестовый режим без телефона: `https://localhost:8443/?fake` (поддельная камера),
`?engine=ios|android|generic` — принудительно выбрать платформенный модуль.
